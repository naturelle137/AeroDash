# Milestones

Read AGENTS.md, the roadmap, relevant requirements, current code and open issues/PRs. Keep scope small enough to deliver a useful workflow. Preserve intended future capabilities; separate implementation presence from integrated test acceptance.

Use the matching operation: `plan.md`, `create.md`, `check.md`, `breakdown.md` or `align.md`. Record concrete scope, acceptance conditions, dependencies and owner. Do not create replacement matrices or process-only work without a concrete delivery need.
