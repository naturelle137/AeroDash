# AeroDash - Central Glossary & Abbreviations

This document serves as the Single Source of Truth (SSOT) for all terminology, abbreviations, and definitions used across the AeroDash project (Requirements, Risk Management, Testing, and Code).

| Term | Definition |
 | :--- | :--- |
| **AFM** | **A**ircraft **F**light **M**anual. Manufacturer's certified document for aircraft operation. |
| **API** | **A**pplication **P**rogramming **I**nterface |
| **ASDA** | **A**ccelerate **S**top **D**istance **A**vailable |
| **AvGas** | **Av**iation **Gas**oline. |
| **BDD** | **B**ehavior **D**riven **D**evelopment. |
| **BEM** | **B**asic **E**mpty **M**ass. |
| **Bilinear Interpolation** | A mathematical method to estimate values within a 2D grid (e.g., Performance Tables). |
| **CG** | **C**enter of **G**ravity. |
| **DZ** | Drizzle |
| **Envelope** | The geometric polygon defining the permissible structural limits for Mass and CG. |
| **FSM** | DE: **F**lug**s**icherheits**m**itteilung (EN: Flight Safety Notification). |
| **ICAO** | **I**nternational **C**ivil **A**viation **O**rganization |
| **LDA** | **L**anding **D**istance **A**vailable. |
| **LL** | **L**ow **L**eaded (in context of aviation fuel). |
| **LM** | **L**anding **M**ass. |
| **METAR** | **MET**eorological **A**erodrome **R**eport |
| **MoGas** | **Mo**tor **Gas**oline. |
| **MTOM** | **M**aximum **T**akeoff **M**ass. |
| **MZFM** | **M**aximum **Z**ero **F**uel **M**ass. |
| **Point-in-Polygon** | A mathematical algorithm used to verify if a given CG/Mass coordinate falls within the Envelope. |
| **POH** | **P**ilot **O**perating **H**andbook. |
| **RA** | Rain |
| **+RA** | Heavy Rain |
| **TAF** | **T**erminal **A**erodrome **F**orecast |
| **TM** | **T**axi **M**ass. |
| **TOD** | **T**ake**o**ff **D**istance (to 50ft). |
| **TOM** | **T**ake**o**ff **M**ass. |
| **TOR** | **T**ake**o**ff **R**un. |
| **TORA** | **T**ake**o**ff **R**un **A**vailable. |
| **UL** | **U**n**l**eaded (in context of aviation fuel). |
| **ZFM** | **Z**ero **F**uel **M**ass. |
