# METAR source

Flight Prep retrieves an observation on request from [wxdecoder](https://wxdecoder.com/api/). Its free, keyless API permits reasonable non-commercial education and situational awareness, requires attribution and cache compliance, and prohibits use as an official briefing or go/no-go authority. Commercial use requires separate permission. On 21 November 2026 `/api/wx/EDDF` returned HTTP 200, `Access-Control-Allow-Origin: *`, a raw report and an observation `reportTime` distinct from retrieval time. Coverage depends on its upstream feeds; absence is shown explicitly. The browser honours the response cache headers. The CSP permits this one origin; no credentials are sent.

The station, raw report and UTC observation time must agree. Unknown, malformed or future timestamps are rejected; observations over one hour old are marked outdated. This threshold is an application warning, not an aviation validity guarantee. Offline, empty and failed requests are distinct from successful observations. A fresh observation with liquid precipitation can default an empty runway condition for the matching ICAO station; the pilot can override it. The suggestion expires with the observation and must be saved explicitly. Saved and manual conditions take precedence. Saved weather-derived conditions retain their station and observation time; the pilot must verify current conditions. Present-weather groups are interpreted using the [Aviation Weather Center METAR format](https://aviationweather.gov/help/data/); vicinity, recent weather, trend forecasts and remarks do not indicate precipitation at the station. Unsupported or malformed report groups do not produce a suggestion. Wet / soft ground is the available unpaved category, not a determination that ground is soft.

A pilot may explicitly replace wind, temperature or QNH individually from a current report. Unsupported, missing or ambiguous values are not offered; wind with a variable direction or reported directional range is not offered. Applied values show station, source and observation time until edited. Wind direction is true; gusts are not applied. An A-group altimeter setting is converted from inHg to hPa using the [NIST conversion factor](https://www.nist.gov/pml/owm/metric-si/unit-conversion/pressure-and-gas-flow-unit-conversions) and rounded to 0.01 hPa. The QNH pressure-altitude method remains a separate pilot choice. Obtain required weather from an authorised briefing source.

The [NOAA Aviation Weather Center API](https://aviationweather.gov/data/api/) documents worldwide METAR access without a key, but a request with an Origin header returned no `Access-Control-Allow-Origin` header; a browser cannot call it directly. [Datamask](https://www.datamask.org/api-docs) excludes flight planning.

## Hourly forecast

[wxdecoder](https://wxdecoder.com/api/) provides free, keyless hourly NWS forecasts for US airports under the attribution and non-commercial terms above. On 21 November 2026 KDFW and KJFK returned CORS-enabled responses; EDDF returned no hourly coverage. The [NWS API](https://www.weather.gov/documentation/services-web-api) describes hourly periods. The selection matches only the exact timestamp provided, interpreted from device local time, with no interpolation. Temperature is converted from °F to °C; compass direction and knots are displayed as supplied. The source's forecast fetch timestamp is not an issue time. Source stale flags or fetch age over four hours suppress application; this threshold is an application warning. Browser caching follows the source headers. Forecast QNH is unavailable; sea-level pressure is never substituted.
