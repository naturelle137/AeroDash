# 312: Playwright BDD

Use `playwright-bdd` to generate Playwright tests from readable `.feature` scenarios with TypeScript step definitions. This reuses Playwright’s browser runner, fixtures, locators and retries. Do not edit generated `.features-gen/` files.

Journeys help describe user-observable acceptance; ordinary links are sufficient. Keep meaningful assertions and functional tags such as `@smoke` and `@wip`. See [Testing](../../testing/TESTING.md) for Chromium commands and evidence limits.
