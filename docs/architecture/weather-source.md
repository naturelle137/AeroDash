# METAR source

Flight Prep retrieves a read-only observation on request from [wxdecoder](https://wxdecoder.com/api/). Its free, keyless API permits reasonable non-commercial education and situational awareness, requires attribution and cache compliance, and prohibits use as an official briefing or go/no-go authority. Commercial use requires separate permission. On 21 November 2026 `/api/wx/EDDF` returned HTTP 200, `Access-Control-Allow-Origin: *`, a raw report and an observation `reportTime` distinct from retrieval time. Coverage depends on its upstream feeds; absence is shown explicitly. The browser honours the response cache headers. The CSP permits this one origin; no credentials are sent.

The station, raw report and UTC observation time must agree. Unknown, malformed or future timestamps are rejected; observations over one hour old are marked outdated. This threshold is an application warning, not an aviation validity guarantee. Offline, empty and failed requests are distinct from successful observations. Weather never changes pilot inputs. Obtain required weather from an authorised briefing source.

The [NOAA Aviation Weather Center API](https://aviationweather.gov/data/api/) documents worldwide METAR access without a key, but a request with an Origin header returned no `Access-Control-Allow-Origin` header; a browser cannot call it directly. [Datamask](https://www.datamask.org/api-docs) excludes flight planning.
